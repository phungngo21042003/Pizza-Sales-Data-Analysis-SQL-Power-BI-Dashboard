# Pizza-Sales-Data-Analysis-SQL-Power-BI-Dashboard
🍕 Pizza Sales Data Analysis | SQL + Power BI Dashboard  An end-to-end data analysis project using SQL Server and Power BI to explore pizza sales performance. Includes revenue insights by category, size, time of day, and best-selling products

# 🎯 Project Overview
This project aims to analyze pizza sales data using SQL for data exploration and Power BI for visualization.
It helps identify key business insights such as total revenue, best-selling pizzas, and peak sales hours.

# 🧩 Dataset: pizza_sales.csv
The dataset contains the following columns:
- pizza_id – Unique identifier for each pizza record in the dataset
- order_id – Unique ID of each order
- pizza_name_id – Identifier linking to a specific pizza type 
- quantity – Number of pizzas of that type sold in a given order
- order_date – Date when the order was placed
- order_time – Time when the order was placed
- unit_price – Price of one pizza
- total_price – Total sales amount for that record (unit_price × quantity).
- pizza_size – Size of the pizza
- pizza_category – Pizza category
- pizza_ingredients – List of ingredients used in that pizza.
- pizza_name – Full name of the pizza

# 🧰 Tools & Technologies
- SQL Server / SSMS – Data analysis and query building
- Power BI – Dashboard visualization
- Excel / CSV – Data source
